# CLS — المرحلة الرابعة: تثبيت الهيدر والهيرو والوسائط (12 أكتوبر 2026)

**المستودع:** `imadtbn/dz_portal`

## الهدف ونطاق التعديل

تحسين استقرار العناصر المرئية في الهاتف، خصوصًا الهيدر وإحصائيات Hero والصور والفيديو المضمّن، دون إعادة تصميم البوابة أو إزالة معلوماتها أو تعديل الإعلانات.

## 1. الهيدر وHero

في `assets/css/style-sector.css`:
- ضبط الحد الأدنى لمساحة محتوى الهيدر عند شاشة هاتف (40px)، ومنع تضخم منطقة الشعار على حساب الأزرار باستخدام `min-width: 0` و`flex: 0 0 auto` للأزرار.
- الحفاظ على الشبكة التي تعرض **ثلاث بطاقات إحصائية في صف واحد** في صفحات القطاعات: `repeat(3, minmax(0, 1fr))`.
- الحفاظ على أبعاد دائرة صورة Hero المرسومة أساسًا في CSS، ودعمها بـ`aspect-ratio: 1 / 1`.
- `font-variant-numeric: tabular-nums` و`white-space: nowrap` لأرقام الإحصائيات فقط، حتى لا تُقسَم الأرقام بعد تغير قيمها.

في `assets/css/style-main.css`:
- جعل إحصائيات Hero الثلاث في الصفحة الرئيسية في صف شبكي واحد على الهاتف، بدل الالتفاف المتوقع من `flex-wrap`.
- تصحيح الخطأ الأصلي `display: block00` إلى `display: block`، وإتاحة مساحة `min-width:4ch; min-height:1.8em` في CSS الأساسي للعدادات التي تُحدَّث بواسطة JavaScript لاحقًا. كان الحجز موجودًا في CSS تحسينات منفصل، لكن تحميله اللاحق قد يتسبب في تغير قياسات النص.

## 4. الفيديوهات

في `assets/css/video-watch.css`:
- يستخدم `.video-watch-player` بالفعل `aspect-ratio: 16 / 9` والحد الأدنى لحجمه حسب الشاشة؛ أُضيف `position:relative` و`overflow:hidden` للحاوية، وأصبح `iframe` بموضع `absolute; inset:0; width:100%; height:100%`.
- هذا يمنع ارتفاعات iframe الخارجية من المشاركة في حساب ارتفاع الحاوية بعد ظهور مشغل Facebook أو YouTube، مع **المحافظة على ارتفاعات الحجز الحالية**: 420px عادة، 520px في صفحات المشاهدة، و240/260px على الهاتف.
- أُضيفت سمات `width="560" height="315"` إلى 13 iframe في صفحات الفيديو والشرح المرتبطة بالبوابة. بقيت عناوين الفيديوهات وروابطها وسلوكها كما هي.
- بقي إطار `pages/process/arpce2.html` دون تغيير HTML لأن تحديثه رُفض في هذه الجلسة؛ ويستفيد مع ذلك من قاعدة `video-watch.css` المشتركة. لا تعتبر هذه الصفحة مستكملة تحديث سمات iframe.

## 5. حماية التعديلات واختبارات القبول

أضيف الملف `tests/cwv-mobile-media.test.js` لاختبار:
- صور Hero في 13 صفحة، وسمات `width/height/loading/decoding/fetchpriority`.
- أبعاد صور البلاغات السبعة وتحميلها الكسول.
- بقاء ثلاث بطاقات إحصاء في Hero وشبكة صف واحد للهاتف.
- ثبات الحجز لإطارات الفيديو في الصفحات الـ13.
- عدم حذف بطاقات القطاعات أو الخدمات، واستمرار تنسيقات AdSense.

توسعت أداة `tools/cls-audit.mjs` لتسجيل أبعاد الهيدر، Hero، الصور، إطارات الفيديو وبطاقات البلاغات.

للتحقق محليًا:

```bash
node --test tests/cwv-mobile-media.test.js
cd tools
npm install
npx playwright install chromium
npm run audit -- --all-widths --compare-ads
```

**حدود التحقق:** تمت مراجعة الملفات المحدثة والاختبارات الشيفرية يدويًا، ولم يُشغَّل الاختبار الكامل على متصفح حي متصل بالإعلانات والوسائط الخارجية. لم تُلتقط مقارنة مرئية حقيقية قبل/بعد هذه التعديلات، ولا يمكن إعلان تحسن رقم CLS في Search Console دون القياس بعد النشر وعلى بيانات المستخدمين الفعلية.

## 6. قبول الانتقال إلى المرحلة الخامسة

- مراجعة شكل Hero وقائمة الهيدر بعروض 320، 360، 390، 412px، دون انزلاق العناصر أو التفاف الإحصائيات إلى صف ثانٍ.
- التأكد من أن iframe لا يغير ارتفاع الحاوية أثناء الشبكة البطيئة، بما في ذلك حالة خطأ خدمة فيديو خارجية.
- التأكد من عدم تغير شكل صور البلاغات المربعة والطويلة والعرضية.
- مراجعة التصرف عند تمكين/حجب AdSense أثناء الاختبار فقط، دون تعطيل الإعلانات في الموقع.
- متابعة CLS وLCP وINP، ثم استكمال المرحلة الخامسة لتحسين ترتيب تحميل CSS والخطوط والسكريبتات.
