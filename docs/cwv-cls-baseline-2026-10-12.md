## 1. نطاق التدقيق والهدف

الهدف هو تحديد التحركات غير المتوقعة في الصفحات عالية التأثر، قبل أي تعديل لتصميم البوابة أو إعلاناتها أو محتواها. الهدف النهائي CLS ≤ 0.10 عند الشريحة 75 من زيارات الهاتف الفعلية؛ لا تكفي تجربة مخبرية وحدها لإثبات بلوغ الهدف.

**تنبيه دقة:** الأرقام التالية نقلٌ من تقرير Google Search Console الذي قدمه مالك الموقع بتاريخ 2026-10-12، وليست قياسات جديدة بواسطة Playwright. تعذر تنفيذ متصفح حي يتصل بالموقع والإعلانات ضمن بيئة إعداد هذه المرحلة؛ لذلك أُضيفت أداة قياس قابلة للتشغيل لاحقًا، وتظل إسنادات الأسباب فرضيات تتطلب التحقق من `LayoutShift`.

## 2. نتائج ثابتة من مراجعة الملفات

1. **الإعلانات:** وُجدت 13 حاوية `.ad-container` في `index.html`، و8 في `sectors/education.html`، و7 في `sectors/awlyaa-education.html`، و5 في `sectors/progres.mesrs.html`، وحاويتان في `pages/process/awlyaa-process.html`. بعض الوحدات `fluid` وبعضها `auto`؛ يجب قياس الأبعاد الفعلية قبل اعتماد ارتفاع مناسب.
2. **CSS الإعلانات:** `assets/css/style-sector.css` يحتوي على `.ad-container { min-height: 100px; }`، بينما `assets/css/style-main.css` و`assets/css/performance-home.css` يستخدمان `280px`. هذه قواعد مختلفة بحسب الصفحات ولا تثبت وحدها مصدر الانزياح.
3. **حجب التخطيط في الأقسام:** `assets/css/performance-home.css` يضع `content-visibility: auto; contain-intrinsic-size: 800px` على أقسام كاملة في الهاتف، و`assets/css/style-main.css` يضع `contain-intrinsic-size: 300px` على `.sector-card`، و`assets/css/style-sector.css` يستخدم `1px 1000px` في `.services-grid`. ينبغي رصد ما إذا كانت القياسات التقديرية تختلف عن الأبعاد الحقيقية أثناء التمرير.
4. **تأخر بعض CSS:** في `index.html` تظهر أنماط مكررة بين `preload` مع `onload` وبين `stylesheet` التقليدي، خاصة `style-section-header.css` و`performance-home.css` وبعض الملفات الإضافية. يجب التحقق من تسلسل التطبيق قبل الإزالة.
5. **تحديث الإحصائيات المؤجل:** `assets/js/deferred-homepage.js` يحمل `homepageStats.js` بعد `load`، والملف الأخير يجلب صفحات القطاعات ويحدّث نص إحصائيات الهيرو وبطاقات القطاعات. يجب معرفة ما إذا كانت هذه التحديثات تغير أبعاد النص أو الصفوف المرئية.
6. **الوسائط الخارجية:** `pages/process/awlyaa-process.html` يتضمن إطار Facebook للفيديو؛ راجع مساحة الإطار قبل التحميل ووقت رسمه.
7. **الخطوط:** يجري تحميل Tajawal وFont Awesome عبر روابط خارجية غير متزامنة في الصفحات ذات الأولوية. تغيير مقاييس الخط والأيقونة عند وصول الملفات احتمال آخر يجب مراقبته.

## 3. طريقة تشغيل القياس المستقل

يتطلب Node.js وPlaywright/Chromium واتصال إنترنت بالجهاز الذي يشغّل الأداة:

```bash
cd tools
npm install
npx playwright install chromium
npm run audit
```

يعطي الأمر السابق نتائج الصفحات الخمس بعرض 390px. للمقارنة عند 360 و390 و412px، ومع وبدون طلبات الشبكات الإعلانية أثناء الاختبار:

```bash
npm run audit -- --all-widths --compare-ads
```

لاختيار مسار معيّن (يطابق جزءًا من اسم الملف):

```bash
npm run audit -- --page=progres.mesrs
```

يمكن ضبط المتغير `CLS_BASE_URL` لقياس نسخة محلية أو معاينة منشورة. توضع النتائج في `tools/cls-audit-output/`، وتشمل:

- `summary.md` لجدول نتائج CLS المخبرية.
- `results.json` لتفاصيل الصفحات والإصدارات.
- `details.json` وثلاث صور `01-initial.png` و`02-settled.png` و`03-end.png` لكل حالة، مع العُقد المتحركة وأبعاد العناصر قبل وبعد التحميل.

**مهم:** نتيجة `ads-blocked` تشخيصية فقط وليست توصية بحجب الإعلانات للمستخدمين، وقد يختلف سلوك شبكة الإعلانات بين الاختبارات.

## 4. شروط الانتقال إلى المرحلة 02

- تسجيل وتحليل تحركات التخطيط الحقيقية إن أمكن في الصفحات الخمس مع الإعلانات فعليًا؛ تحديد الحدث واللحظة والمكون المتسبب بدل التخمين.
- تحديد أبعاد الحاويات الإعلانية قبل وبعد ملئها عند 360 و390 و412px.
- فحص التغيّر في ارتفاع `hero` و`hero-stats` و`.sectors-section` عند وصول CSS والخطوط والإحصائيات.
- إجراء لقطات مقارنة أولية ثم اختبار إصلاح محدود، أولًا في صفحات `education.html` و`awlyaa-education.html`.
- عدم تعديل المظهر أو عدد الإعلانات أو تعطيل الوظائف الأساسية لمجرد تحسين المقياس.
